# 给 Claude 的视频制作任务

请为 Project+ AI 制作 Metropolis 参赛视频，沿用当前已上线的简洁橙色 Agent 界面。

1. 先读 CLAUDE_VIDEO_HANDOFF.md，按其时间轴制作技术演示（目标 2:45，最多 3:00）和 Pitch（目标 1:40，最多 2:00）。
2. 使用 DEMO_EVIDENCE.md 的合成资料。不要展示真实客户资料、账户密码、评审码或任何环境文件。
3. 真实录制 Agent 查找标准、检索证据、请求 Human Input、人工确认、新任务继续的过程。不要用动画或预写文字伪造模型调用。
4. Monad 已部署。按 MONAD_READINESS.md 实录链上验证。公开演示记录是单独的“网络”Human Input 样本，不能声称是本次完整验收报告。录完验收场景后也可以导出当前项目，并用本机签名脚本生成该场景自己的证明。
5. 输出两个 1080p MP4、对应英文 SRT、封面。用户会提供上传平台；返回两个可直接观看的 HTTPS 链接后才能补齐比赛表单。
6. Pitch 的本人介绍可以由创始人录音/出镜；不要未经授权克隆声音或虚构姓名、公司规模、营收和客户指标。
